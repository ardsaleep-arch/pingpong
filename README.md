# 🏓 Ping Pong

เกม Ping Pong (Pong) บนเว็บ เขียนด้วย HTML, CSS และ JavaScript ล้วน ในไฟล์เดียว (`index.html`)

## ฟีเจอร์

- **เล่นกับ AI** 3 ระดับ: ง่าย, ปานกลาง, ยาก
- **ผู้เล่น 2 คน** บนเครื่องเดียวกัน (iPad: คนละครึ่งสนาม ใช้นิ้วพร้อมกันได้)
- เลือกแต้มที่ชนะ: 5, 11 หรือ 21 แต้ม
- ลูกบอลเร็วขึ้นทุกครั้งที่ตีโดน มุมลูกขึ้นกับตำแหน่งที่โดนไม้
- เสียงประกอบ (ปิดได้) และหยุดเกมอัตโนมัติเมื่อสลับแอป

## วิธีเล่น

- **iPad / โทรศัพท์:** ลากนิ้วขึ้นลงบนครึ่งสนามของคุณเพื่อขยับไม้ แตะสนามเพื่อเสิร์ฟ
- **คอมพิวเตอร์:** ผู้เล่นซ้ายใช้ `W` / `S` หรือเมาส์ · ผู้เล่นขวาใช้ `↑` / `↓` · `Space` หยุด/เล่นต่อ

สนามปรับขนาดให้พอดีหน้าจอโดยอัตโนมัติ รองรับทั้งแนวตั้งและแนวนอน และคมชัดบนจอ Retina

## เริ่มใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
